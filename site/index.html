How to play

Lineup

Every day there's a new cape to identify, in two files. In the Lineup, guess any cape: it's compared with the target on seven details. Guess as many times as you need.

  • ✓ Green: matches.
  • ≈ Amber: close. They share a power class, or first appear within 2 arcs of each other.
  • ✗ Red: no match.
  • ▲▼ On First appearance: the target first appears later (▲) or earlier (▼).

Tap any column heading to see what it means and the values it can take.

Lineup hints

  • After 2 wrong guesses: which story introduced the cape (Worm, PRT Quest, Glow-worm, Ward or PHO Sunday).
  • After 4: whether they're a cluster cape.
  • After 8: you can reveal the answer, though the file then counts as unsolved.

First appearance counts through the stories in that order. PRT Quest and PHO Sunday each count as a single step.

Power file

Read a description of the cape's power with their names blacked out. You have 7 guesses.

Wrong guesses open extra notes about the cape. The power class note lists any secondary classes too.

A few rules

  • Names, cape names and civilian names all count. Skitter, Weaver and Taylor Hebert are the same answer.
  • New files arrive at midnight CET. Missed one? Open it from the Archive. Want more? Press Practice for a random cape; practice files don't count in your stats.
  • Wormdle is in beta: not every cape's file is finished yet. Unfinished capes can still be guessed, but some details show as "Not on file".
  • Found a bug, a wrong detail, or have a suggestion? Email contact@raunaksarbajna.com.

New in the Lineup

Some capes were too hard to tell apart, so the Lineup has a seventh detail.

First appearance

Every guess now shows the arc where that cape first appears. An arrow tells you whether the subject first appears later (▲) or earlier (▼), and the tile turns amber when you're within 2 arcs. Arcs run on in reading order through Worm, PRT Quest, Glow-worm, Ward and PHO Sunday.

Also new this week

  • After 2 wrong guesses, Introduced in tells you which story the cape first appeared in: Worm, PRT Quest, Glow-worm, Ward or PHO Sunday.
  • After 4 wrong guesses, Cluster cape tells you whether they're part of a cluster.
  • Truly stuck? After 8 guesses, you can reveal the answer. The file counts as unsolved.

The files have been reorganised

A big update to the cape files changed many details, so every daily answer, past ones included, has been drawn again. Your earlier results were for answers that no longer exist, so they've been cleared and your stats start fresh.

New files now arrive at midnight in your own time zone.

Wormdle is in beta

The cape files are still being written. Right now some of the capes on record have complete files. Only those can be a day's answer, and only those give reliable results when you guess them.

You can still guess any cape. If its file isn't finished, some of its details show as "Not on file", so a guess may not compare the way you'd expect.

Spoilers for all of Worm and Ward

The answers come from both stories, start to finish. The clues include who ends up dead, which side a cape ends up on, and secret identities. If you're still reading, you may want to come back later.
