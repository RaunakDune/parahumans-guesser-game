# Art

`riverfront.svg` is an original placeholder illustration made for this project and released under
[CC0](https://creativecommons.org/publicdomain/zero/1.0/). Replace it with commissioned art whenever it's ready:

- Keep the file name and drop in a new `riverfront.svg`, or
- use a `.jpg`, `.png` or `.webp` and change the `url(../assets/riverfront.svg)` line in `css/style.css`.

A wide landscape image (at least 2400 × 1350) works best. The page darkens the top of the image so the title
stays readable, and the case file covers the middle, so keep the main detail toward the edges and the bottom.

`og-image.png` is the preview picture shown when the link is shared. It's 1200 × 630; replace it at the same size.
